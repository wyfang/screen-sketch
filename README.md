# ScreenSketch（屏幕绘图器）

将图片转换成黑白笔迹，并通过 macOS 鼠标事件绘制到指定屏幕区域的本地应用。

[完整使用说明](./使用说明.txt) · [English](./README.en.md)

## 功能

- 四种绘制效果：轮廓线稿、黑白照片、素描排线、实心填充；预览由实际笔画路径和笔宽渲染。
- 曝光、对比度、阴影提亮，以及实心填充的黑白阈值调节；松开滑杆后更新预览和绘制路径。
- 拖拽或两点框选画布，使用 Quartz 屏幕点计算坐标，区分 Retina 预览像素与鼠标移动距离。
- 联合校准最小有效位移、X/Y 间距、移动速度与收笔等待／补偿；记录画笔、橡皮按钮位置，重放校准笔迹清理测试区。
- 调整绘制速度；前台模式下任意键盘或手动鼠标操作暂停，点击“继续”从暂停位置恢复。
- 新图片优先生成当前模式，各效果完成后分别显示，过期任务不会覆盖新预览。

## 使用

### 构建与启动

需要 macOS 14 或更新版本，以及 Apple Command Line Tools 或已配置的 Xcode。应用运行时不依赖 Python、Node.js 或外部 AI 服务。

```bash
git clone https://github.com/wyfang/screen-sketch.git
cd screen-sketch
bash build.sh
open ./屏幕绘图器.app
```

未安装编译工具时，先执行 `xcode-select --install`。如果系统选中了尚未完成设置的 Xcode，但已安装 Command Line Tools，可使用：

```bash
DEVELOPER_DIR=/Library/Developer/CommandLineTools bash build.sh
```

构建输出为仓库根目录的 `屏幕绘图器.app`，采用当前 Mac 架构和本机临时签名；脚本不会安装或覆盖 `/Applications`。应用未做 Apple 公证。

### 绘制

1. 导入图片，在目标画板选择黑笔并设置笔宽。
2. 框选实际画布，填写画笔在屏幕上的实际宽度；需要自动切换工具时，定位画笔和橡皮按钮。
3. 运行联合校准，选择合格结果并应用，再选择绘制模式和图片调节参数。
4. 在系统设置的“隐私与安全性 → 辅助功能”中允许应用，先试画一笔，再开始绘制。

前台绘制占用系统鼠标，只按屏幕坐标发送，不检测目标进程存活或前台焦点。运行中保持画布和工具位置不变；任意键盘、鼠标移动、点击或滚轮操作会暂停，继续需要点击应用中的按钮。

自动清理会在真实画布上沿本次启动记录的校准路径使用橡皮；实际擦除范围由目标画板的橡皮大小决定。它不会主动清空整幅画布。

### 测试

```bash
bash test.sh
bash test.sh EngineSpeedChecks EngineTargetChecks
```

自动测试使用事件接收器和临时生成的图片，不向实际画板发送绘制事件。测试产物保存在 `.build` 中，不进入版本管理。需要使用自己的图片验证预览时，可设置 `SCREEN_SKETCH_TEST_IMAGE`。

## 说明

图片处理在本机完成，不上传导入文件，不需要 API 密钥。系统辅助功能权限用于发送鼠标事件与监听暂停操作；应用不需要屏幕录制权限。

后台模式为试验功能，依靠向目标进程投递鼠标事件，不会创建第二个系统鼠标。微信小程序、Figma 和浏览器画板是否接收取决于目标软件；需先确认试画结果。后台目标不可用时暂停保留进度，不会自动改投其他进程。

预览使用固定笔宽模拟目标笔迹；画板自身的平滑、事件响应、抗锯齿与收笔行为仍可能带来差异。实际黑笔宽度、校准参数和画布尺寸决定精度，达到路径预算时会降低整幅图的采样并显示说明。实心填充不保留连续灰阶，原图已经纯白的细节不能靠图片调节恢复。

`Sources` 保存应用源码，`Tests` 保存回归检查，`Tools` 保存图标生成、预览导出、离屏界面渲染和独立测试画板。完整操作流程见[使用说明](./使用说明.txt)。
